## 发布为个人主页

1. 在 GitHub 账号 `renfan23` 下新建公开仓库，仓库名填写 `renfan23.github.io`。
2. 将本文件夹内的文件上传到仓库根目录。
3. 在仓库的 **Settings → Pages** 中选择从 `main` 分支的根目录发布。
4. 发布后访问 [https://renfan23.github.io/](https://renfan23.github.io/)。首次发布可能需要几分钟。
