# XXX 个人学术主页

这是一个基于 Academic Pages / Jekyll 结构的 GitHub Pages 个人主页，参考了 [zhangyan19950601/yanzhang.github.io](https://github.com/zhangyan19950601/yanzhang.github.io)。

## 主要编辑位置

| 内容 | 文件 |
| --- | --- |
| 姓名、邮箱、头像、单位、GitHub | `_config.yml` |
| 首页个人简介、新闻、研究方向 | `_pages/about.md` |
| 顶部导航 | `_data/navigation.yml` |
| 论文 | `_publications/*.md` |
| 学术报告 | `_talks/*.md` |
| 教学经历 | `_teaching/*.md` |
| 项目与作品 | `_pages/portfolio.html` |
| 个人简历 | `_pages/cv.md` |
| 头像 | `images/profile.png` |

提交到 `main` 分支后，GitHub Pages 会自动构建更新。
